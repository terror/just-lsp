`just-lsp` is also available through these package managers:

- [Homebrew](https://formulae.brew.sh/formula/just-lsp): `brew install just-lsp`
- [Nix](https://github.com/NixOS/nixpkgs/blob/master/pkgs/by-name/ju/just-lsp/package.nix):
  `nix-env -iA nixpkgs.just-lsp`
- [Alpine Linux](https://pkgs.alpinelinux.org/package/edge/testing/x86_64/just-lsp)
  (edge/testing): `apk add just-lsp`
- [Arch Linux](https://archlinux.org/packages/extra/x86_64/just-lsp/):
  `pacman -S just-lsp`
- [Void Linux](https://github.com/void-linux/void-packages/tree/master/srcpkgs/just-lsp):
  `xbps-install -S just-lsp`
